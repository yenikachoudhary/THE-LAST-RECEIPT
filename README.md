# EvidenceBoard — Digital Investigation Game

EvidenceBoard is an interactive web-based detective game where players analyze digital trails—transaction spikes, spending patterns, network entities, and travel shares—to uncover shifts in a suspect's routine and solve cases.

---

## 🛠️ Tech Stack

* **Framework:** React + Vite
* **Styling:** Tailwind CSS
* **Animations:** Motion (`motion/react`)
* **Icons:** Lucide React (`lucide-react`)
